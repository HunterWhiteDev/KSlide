# KScroll

A Sliding/Scrolling Window Manager for KWin/KDE Plasma with multi monitor support.

# Installation 
KScroll can be installed by one of the following methods:

1) [The KDE Store]()
Install the script how you would any other script through the link on the store.

2) Compiling from source
You can clone the repo and run this command: `npm run compile && npm run install`

# Shortcuts 
These are the default shortcuts. You can change these by going into System Settings > Keyboard > Shortcuts > Window management. All shortcuts are prefixed with the word KScroll for convenience.

| Shortcut  | Action |
| ------------- | ------------- |
| `Meta` + `A` | Focuses the window to the left  |
| `Meta` + `D` | Focuses the window to the right  |
| `Meta` + `E` | Increase width of current column |
| `Meta` + `W` | Decrease width of current column  |
| `Meta` + `G` | Moves current window to the column to the left |
| `Meta` + `G` | Moves current window to the column to the right |
| `Meta` + `M` | Makes the windows in the column take up an equal amount of maximum space |
| `Meta` + `ctrl` + `A` | Swaps the current column with the column to the left |
| `Meta` + `ctrl` + `D` | Swaps the current column with the column to the right |
| `Meta` + `shift` + `A` | Moves the view port to the column to the left without focusing the left column |
| `Meta` + `shift` + `D` | Moves the view port to the column to the right without focusing the right column |
